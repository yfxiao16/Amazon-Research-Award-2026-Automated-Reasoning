Beyond the first year, we expect these results to extend to further decidable classes of architectures and to contracts with probabilistic guarantees. Contracts compiled into reward machines~\cite{icarte2018reward,camacho2019ltl} also give step-wise rewards that are checked formally, which we plan to use to fine-tune small open models. All code, benchmarks, and run traces will be released under open-source licenses.
