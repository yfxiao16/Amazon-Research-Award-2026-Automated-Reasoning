\section{Additional information}

\textbf{1. Application domain and analysis techniques.} Compositional design of distributed systems, multi-robot systems, and hardware, using \gls{ag} contracts, mixed-integer linear programming (Gurobi), \gls{ltl} model checking (nuXmv), \gls{smt} reasoning, GR(1) synthesis (slugs), and hardware model checking (SymbiYosys, Jasper). It covers sound neurosymbolic reasoning, LLM--solver interfaces, vacuity and inconsistency detection, distributed systems, and formal models of hardware.

\textbf{2. Current applications.} \chase has been used for requirement formalization and validation of cyber-physical systems~\cite{nuzzo2018chase}, contract-based architecture exploration~\cite{xiao2024contrarc,xiao2026smcp}, and consistency and availability analysis of distributed systems with Lockheed Martin~\cite{xiao2026memocode}. Our RTL flow runs on OpenTitan and HierSVA designs.

\textbf{3. Potential applications to Amazon.} (i) Distributed cloud services, where end-to-end latency, availability, and consistency budgets can be decomposed into per-component timing contracts~\cite{xiao2026memocode}, complementing protocol-level models in TLA+ or P. (ii) Amazon Robotics fleets, where missions can be decomposed hierarchically into contracts for small groups of robots~\cite{xiao2026acies}, and learned \gls{vla} policies can be guarded at run time by contract monitors and post-trained with contract-based rewards. (iii) Verification of AWS processors and accelerators, where end-to-end properties of blocks such as interconnects, DMA engines, and cache-coherence controllers that exceed direct model checking can be decomposed into module-level SVA contracts and reused when a block is resized.

\textbf{4--5. Prior Amazon Research Awards.} No\yifeng{, and no Amazon funding or AWS credits in the past three years}.

\textbf{6. Assumptions and soundness.} A certified result is sound when (i) the back ends return correct verdicts; (ii) the translation into each back end preserves the semantics of the contracts; (iii) the embeddings between formalisms are conservative approximations, and learned components guarded only at run time are excluded from the certificate; and (iv) the top-level specification is correct, so agent-written contracts are checked for consistency and vacuity. Bounded results never count as proofs, and LLM outputs are never trusted.
